# تحديث ونس — ٦ نوفمبر ٢٠٢٦

## أولًا: الأعطال اللي اتصلحت
| العطل | السبب | الحل |
|---|---|---|
| «محتاج تسجيل دخول» عند رفع أي ملف وإنت مسجل | كود الرفع (`lib/upload.ts`) كان بيقرأ رابط Supabase من `process.env` بس، وده بيطلع فاضي في نسخة الـ APK | بيقرأ من `lib/supabase.ts` (`SUPABASE_URL`) اللي بيرجع لـ `app.config.ts`، ولو الجلسة منتهية بيجددها تلقائيًا |
| «نوع الملف مش مدعوم» للصوت | زر «صوت من الجهاز» كان بيستخدم فلتر الملفات (PDF/Word/نص)، وتسجيل الصوت كان بنوع `audio/m4a` | زر صوت مستقل (`pickAudio`) + توحيد أنواع MIME حسب الامتداد (`normalizeMime`) |
| القصة: «النشر مش تم / جرّب تاني» | أخطاء Supabase مش `Error` فكانت الرسالة بتضيع | `lib/errors.ts` بيطلّع السبب الحقيقي؛ والقصة بتنشر بالأساسيات لو عمود ناقص في السيرفر |
| رفع القصص والتعليقات والشات | مسار رفع تاني بيستخدم Blob (بيفشل على الموبايل) | كل الرفع بقى عبر `uploadWithProgress` |
| المجلس بيخرج لتطبيق Jitsi | صفحة Jitsi بتحوّل لتطبيقها | `disableDeepLinking` + منع روابط `org.jitsi.meet://` + طلب صلاحية المايك قبل الدخول؛ الغرفة تفضل جوه ونس |
| تغيير اليوزر نيم | الكود يعدّل نفس الصف، لكن النتيجة ما كانتش بتتأكد | التحديث بيتأكد إن صف اتعدل فعلًا، ويعرض سبب الرفض (مثلًا محجوز) |
| متغيرات البيئة في GitHub | Secret ناقص = نص فاضي والكود كان بيستخدم `??` | اتغيّرت لـ `||` |

## ثانيًا: مميزات جديدة
- **الإشعارات (حسب PDF ٤ نوفمبر):** بحث مع فلاتر وتمييز الكلمة · «تمييز الكل كمقروء» مع تراجع · قائمة ⋮ لكل إشعار حسب النوع · تثبيت (حد ٥) / إخفاء / حذف مع «تراجع» ٥ ثوانٍ · قبول/حذف الصداقة من البطاقة · تفاعل ورد على التعليق · الانتقال لمكان الإشعار.
- **المجالس:** شريط علوي تحت الـ Safe Area وأزرار ≥ ٤٨dp · زر دخول كبير ٥٦dp · نسخ الرابط فعليًا مع «تم نسخ الرابط ✔» · قائمة ⋯ (إبلاغ/إنهاء/حذف) بدل الأيقونات الخطرة · أسماء الحضور الحقيقية.
- **كارت المنشور:** زرّا «شارك» و«تنزيل» بقوا شغالين (كانوا نص بس).
- **الأندرويد:** صلاحيات الميكروفون والكاميرا والوسائط معلنة.

### بناء APK من GitHub (من غير Expo/EAS)
1. ارفع المشروع على GitHub (فرع `main`).
2. من تبويب **Actions** شغّل «Build Android APK» (أو يشتغل تلقائيًا مع كل push).
3. بعد ما يخلص، حمّل `wanas-apk` من **Artifacts**.
4. (اختياري) Secrets: `EXPO_PUBLIC_SUPABASE_URL` و`EXPO_PUBLIC_SUPABASE_ANON_KEY` — لو مش مضافين بيتاخدوا من `app.config.ts`.
> مفتاح توقيع النسخة من GitHub مختلف عن نسخة EAS القديمة: امسح التطبيق القديم من الهاتف قبل تثبيت الجديد.

### قاعدة البيانات (مرة واحدة)
شغّل `supabase/migrations/20261105000100_notifications_pin_hide_comment_reactions.sql` من Supabase → SQL Editor. من غيره التثبيت والإخفاء بيتحفظوا على الجهاز بس، وتفاعل التعليق من الإشعار مش هيشتغل.
